01 / COMBAT ROBOTICS
Concept illustration
Combat roboticsApril 2026

VELOS

I led the electronics and system integration for a combat robot, bringing its motors, spinning mechanism, radio controls, batteries, and embedded electronics together in a 10-day concept-to-build cycle.

ESP32KiCadESCsRC controlPower distribution

My work: Electrical subsystem design, embedded control, PCB design, wiring, integration, and testing.

Read project details ↗

The project

VELOS is a 15 kg drum-spinner combat robot. Its electrical system connects the battery, motor controllers, and radio-control inputs so the drivetrain and spinning mechanism can operate together.

My contribution

I designed and validated power distribution for the drive and weapon ESCs and regulated power for the control electronics. I integrated a hardwired master kill switch for emergency isolation and designed a KiCad PCB for ESP32-based control and signal distribution.

Control & integration

I developed ESP32 control for RC command processing, ESC signals, sensor interfaces, power monitoring, and a communication-loss failsafe. I also fabricated a custom Y-splitter and wiring harnesses, then soldered, integrated, tested, and troubleshot the system.

Engineering lessons

This project gave me hands-on experience connecting high-power hardware with low-voltage control electronics. After the competition, I investigated ESC overcurrent failure and PCB microfractures, extending the work from building a system to understanding its failure modes.

Broader application

The same integration challenges appear in mobile robots and other motor-driven systems: distributing power, processing commands, organizing wiring, and planning a safe shutdown.

02 / AUTOMATION & SENSING
Concept illustration
Automation & sensingJanuary 2026

Color-sensing robotic arm

I built a two-joint robotic arm that detects an object’s color and sorts it automatically, combining light sensing, coordinated servo motion, and an electromagnetic gripper.

ArduinoPWMRGB LED / LDRServo motors

My work: Arm design, color-sensor calibration, coordinated motion, and component integration.

Read project details ↗

The project

The goal was autonomous object sorting. A two-joint arm moves an electromagnetic gripper, while a color-sensing module helps the controller decide how to sort each object.

My contribution

I designed a 2-DOF RR servo-actuated arm with coordinated PWM motion control. I engineered and calibrated an RGB LED–LDR module, using threshold-based color detection under varying ambient-light conditions, and integrated it with Arduino control and the gripper.

Engineering lessons

The project connected sensor calibration with physical motion. It developed my experience in PWM control, sensor interfacing, and integrating detection, movement, and gripping into an autonomous sequence.

Broader application

Color-based sorting illustrates how automated systems can combine sensing and actuation for repetitive handling tasks, a principle used in manufacturing and materials sorting.

The project

The tablet turns sensed input into coordinate data that a host device can receive. It brings together input sensing, embedded processing, and device communication.

My contribution

I integrated touch/input sensing with an ESP32, programmed real-time acquisition and coordinate mapping, and implemented serial/wireless data transmission to the host device. I designed, assembled, debugged, and tested the electronic system.

Engineering lessons

This work developed my experience in Embedded C, sensor interfacing, and real-time processing. It also required me to debug the complete path from physical input to transmitted coordinates.

Broader application

The project demonstrates the principles behind connected input devices: acquire a signal, process it into useful information, and communicate it to another system.
